# Proposal: Add Beach-Ocean Background

## Overview

将现有的天气背景组件重构为沙滩海洋背景，参考 [beachx](https://github.com/ildarnm/beachx) 项目的实现思路，但采用左右结构布局（左侧海洋，右侧沙滩），而非原项目的上下结构。

## Motivation

当前的天气背景组件实现了基本的天空和海洋效果，但缺乏更真实的沙滩和波浪动画。通过引入 beachx 项目的技术（Simplex 噪声生成的波浪、多层海浪效果等），可以创建更具视觉吸引力的背景体验。

## Goals

- 实现左右布局的沙滩海洋背景（左侧 35% 海洋区域，右侧 65% 沙滩区域）
- 使用 Simplex 噪声算法生成自然的海浪波动效果
- 实现多层海浪渲染，创造深度感
- 支持波浪的周期性运动（来回运动）
- 保持现有的性能优化特性（质量设置、设备检测）
- 保持现有的天气条件支持（晴天、多云、雨天等）

## Non-Goals

- 不改变现有的 WeatherBackground 组件接口
- 不移除现有的天气条件配置系统
- 不影响其他组件的功能
- 不实现太阳轨迹动画（由 `enhance-weather-background-realism` 处理）
- 不实现植被和鱼类元素（由 `enhance-weather-background-realism` 处理）

## Design Considerations

### 布局结构

- **左侧海洋区域（35%）**：显示多层波浪动画，垂直方向的波浪曲线
- **右侧沙滩区域（65%）**：静态沙滩背景，带有细微的沙粒纹理

### 技术方案

1. **Simplex 噪声**：使用 `simplex-noise` 库生成平滑自然的波浪运动
2. **多层渲染**：实现 3-4 层海浪，每层具有不同的颜色、透明度和运动速度
3. **性能优化**：根据设备性能调整波浪层数和粒子数量

### 与 beachx 的差异

| 特性     | beachx                                | 本方案                 |
| -------- | ------------------------------------- | ---------------------- |
| 布局方向 | 上下（上海洋，下沙滩）                | 左右（左海洋，右沙滩） |
| 波浪方向 | 水平波浪（横向移动）                  | 垂直波浪（上下波动）   |
| 架构     | 独立类系统（Layer, Wave, WaveRender） | React 组件集成         |
| 波浪行为 | 周期性覆盖和退回                      | 持续波动效果           |

## Dependencies

需要添加新的依赖项：

```json
{
  "simplex-noise": "^4.0.0"
}
```

## Risks & Mitigations

| 风险         | 影响                       | 缓解措施                                   |
| ------------ | -------------------------- | ------------------------------------------ |
| 性能下降     | 低端设备卡顿               | 保留现有的质量设置系统，动态调整波浪层数   |
| 视觉不协调   | 与现有 UI 风格不匹配       | 使用柔和的颜色方案，确保背景不抢占前景内容 |
| 浏览器兼容性 | 某些浏览器不支持 Canvas 2D | 添加降级方案，检测 Canvas 支持             |

## Alternatives Considered

1. **保持上下布局**：与 beachx 相同，但不符合用户需求
2. **使用 CSS 动画**：性能更好但视觉效果有限
3. **使用预录视频**：视觉效果好但文件体积大

## Success Metrics

- 在中等配置设备上保持 60 FPS
- 波浪动画流畅自然
- 用户反馈积极
- 不影响页面加载时间（增量 < 100KB）
