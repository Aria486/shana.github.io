# 提案总结: 增强天气背景真实感

## 📋 基本信息

- **变更 ID**: `enhance-weather-background-realism`
- **类型**: 改进 (Improvement)
- **预估工作量**: 2-3 天
- **状态**: ⏳ 待审核

## 🎯 核心目标

解决当前天气背景的5个主要问题:

1. ❌ **太刺眼** → ✅ 柔和配色 (降低饱和度 + 半透明)
2. ❌ **布局不真实** → ✅ 横向布局 (左海右滩)
3. ❌ **占比过大** → ✅ 高度控制 (≤30% 视口)
4. ❌ **太阳固定** → ✅ 动态轨迹 (6am-6pm 从左到右)
5. ❌ **场景单调** → ✅ 增加植被 (椰子树/灌木) 和鱼类

## 📐 技术方案概览

### 1. 场景布局重构 (阶段1: 0.5天)

```
修改前:                修改后:
┌─────────┐           ┌─────┬─────┐
│  天空    │           │ 海洋│沙滩 │ ← 横向分割
├─────────┤    →      ├─────┼─────┤
│  海浪    │           │35% │ 65% │
├─────────┤           │     │     │
│  沙滩    │           │     │     │
└─────────┘           └─────┴─────┘
垂直堆叠              左海右滩
```

**关键变更**:

- 海洋占左侧 35% 宽度
- 沙滩占右侧 65% 宽度
- 整体高度从 100% → 30% (桌面) / 20% (移动)

### 2. 太阳动态系统 (阶段2: 1天)

```
时间轴:  6am    9am    12pm   15pm   18pm   22pm
        ╱ ●    ◉     ☀      ◉     ● ╲   ☾
       ╱  低   高    最高    高    低  ╲  月亮
      ╱─────────────────────────────────╲
     日出                              日落
```

**核心算法**:

- 水平位置: 线性映射 6am(10%) → 18pm(90%)
- 垂直位置: 抛物线 (正午最高)
- 夜间 (18:00-6:00): 显示月亮
- 更新频率: 每秒1次 (性能优化)

### 3. 场景元素增强 (阶段3: 1天)

**新增元素**:

- 🌴 **椰子树** 2-3棵 (沙滩区)
  - 褐色树干 + 绿色叶片
  - 高度 60-80px
- 🌿 **灌木** 3-5簇
  - 多个圆形组成
  - 半透明深绿色
- 🐟 **鱼类** 5-10条 (海洋区)
  - 椭圆身体 + 三角尾巴
  - 水平游动 + 垂直摆动
  - 边界反转

### 4. 颜色柔和化

| 天气 | 修改前 (刺眼)    | 修改后 (柔和)                      |
| ---- | ---------------- | ---------------------------------- |
| 晴天 | `#87CEEB` 鲜艳蓝 | `rgba(135,206,235,0.3)` 淡蓝半透明 |
| 雨天 | `#696969` 深灰   | `rgba(105,105,105,0.5)` 柔和灰     |
| 夜间 | (无)             | `rgba(25,25,112,0.8)` 深蓝夜空     |

## 📊 性能优化策略

| 优化项   | 方法            | 收益              |
| -------- | --------------- | ----------------- |
| 植被渲染 | 离屏Canvas缓存  | 5ms → 0.5ms (10x) |
| 鱼类更新 | 每2帧 (30fps)   | CPU -30%          |
| 太阳计算 | 每秒1次         | 60次/秒 → 1次/秒  |
| 质量分级 | high/medium/low | 低端设备流畅      |
